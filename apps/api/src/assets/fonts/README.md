# PDF shriftlari

`DejaVuSans` — Konsilium PDF hisobotlari uchun.

PDFKit ning ichki `Helvetica` shrifti WinAnsi kodlashda bo'lib, **kirill harflarini
qo'llab-quvvatlamaydi** — ruscha PDF ochilganda matn buzilib chiqardi. DejaVuSans
quyidagilarni qamrab oladi:

- Kirill (rus va o'zbek: `ғ қ ҳ ў`)
- O'zbek lotin `ʻ` (U+02BB)
- Tipografik belgilar: `—`, `°`
